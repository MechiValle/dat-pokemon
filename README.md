Game built with React and TypeScript where players must determine which anime is newer or older.

## Features

- Pokémon data fetched from PokeAPI
- Local caching and debounced search to reduce API requests
- Streak and timer system
- Responsive design
- TypeScript throughout the application

## Tech Stack

- React
- TypeScript
- Vite
- PokeAPI
