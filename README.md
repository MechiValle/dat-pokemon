Game built with React and TypeScript where players must guess which Pokémon is being referenced from silhouettes, cries, and cropped/zoomed images.

## Features

- Pokémon data fetched from PokeAPI
- Local caching and debounced search to reduce API requests
- Streak and timer system
- Responsive design
- TypeScript throughout the application

## Tech Stack

- React
- TypeScript
- Next.JS
- PokeAPI
